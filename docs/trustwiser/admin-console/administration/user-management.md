# User Management

Use **User Management** to create, configure, and govern user accounts within your organization's tenant. Assigning specific roles and departments enforces role-based access control relevant to their responsibilities.

To access, go to **Administration** > **User Management**.

<div align="left" data-with-frame="true"><figure><img src="../../../.gitbook/assets/User Management.png" alt=""><figcaption></figcaption></figure></div>

### Adding a User

* Select '+' to initiate adding a new tenant user.
* Enter the user's **Email** and **Name**.
* Set a **Password** for the user to access his/her account.
* Select the user's **Role** and **Department** (if required).
*   Then, select **Create User**.<br>

    <div align="left" data-with-frame="true"><figure><img src="../../../.gitbook/assets/Add user.png" alt="" width="563"><figcaption></figcaption></figure></div>

The platform creates the user and is listed in the users list. The user account is activated by default.

### Manage Users

Use the controls in the "Actions" column of the Users table to maintain user accounts.

* Select the **Active / Deactivate** (<img src="../../../.gitbook/assets/Activate-Deactivate icon (1).png" alt="" data-size="original">) option to toggle a user's status.&#x20;
* Select **Edit** (<img src="../../../.gitbook/assets/Edit User - icon (1).png" alt="" data-size="original">) option to modify a user's name, role, or department.
* Select **Delete** (<img src="../../../.gitbook/assets/Delete user.png" alt="" data-size="original">) to permanently remove a user account from the tenant.
